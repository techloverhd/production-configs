# Self-Hosted Nginx Proxy Manager

Intuitive web UI reverse proxy with automated Let's Encrypt SSL certificates, HTTP/2 support, and IP access lists.

Full step-by-step walkthrough: [Self-Host Nginx Proxy Manager in Docker Guide (TechLoverHD)](https://techloverhd.com/2026/11/self-host-nginx-proxy-manager-docker-guide/)

## Quick Start

1. Start NPM:
   ```bash
   docker compose up -d
   ```
2. Open `http://<your-server-ip>:81` in your browser.
3. Default credentials:
   - Email: `admin@example.com`
   - Password: `changeme`
4. Immediately change the default email and password upon first login.
