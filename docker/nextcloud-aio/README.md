# Self-Hosted Nextcloud All-in-One (AIO)

Enterprise-grade private cloud storage setup with automated daily backups, Collabora online document office, Redis caching, and PostgreSQL.

Full step-by-step walkthrough: [Self-Host Nextcloud AIO in Docker Guide (TechLoverHD)](https://techloverhd.com/2026/10/self-host-nextcloud-aio-docker-guide/)

## Quick Start

1. Launch the master container:
   ```bash
   docker compose up -d
   ```
2. Open `https://<your-server-ip>:8080` in your web browser.
3. Save the generated passphrase and configure your domain.
